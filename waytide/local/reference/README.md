# `waytide/local/reference/` — source material this project is written against

This directory holds documents that originate outside this repository and are read here as
**source material**. Nothing in it is this project's own statement, and nothing in it binds.

**A file here is a verbatim copy and is not edited.** It records what its source said at the
moment it was taken. Correcting it, reformatting it, or conforming it to this project's
vocabulary would cost the one thing a copy is for. The foundation package's disclosure rule
governs the single exception.

**A file here takes no datetime prefix and no provenance footer.** It is neither a dated
decision in this project's history nor a document this project authored. It keeps the name it
had, prefixed by the repository it came from, so a reader can find the original.
